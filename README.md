# MK EARNING Frontend v1.0

This is a responsive static UI preview for the MK EARNING project.

## Open on Android (Acode)
1. Download and extract `MK-EARNING-FRONTEND-v1.zip`.
2. Open Acode and choose the extracted `MK-EARNING-FRONTEND-v1` folder.
3. Open `index.html`.
4. Use Preview / browser preview.
5. On the home page, choose User Dashboard, Admin Login, or Super Admin Login.

## Included pages
- User dashboard, ads, withdrawal
- Admin login and dashboard
- Separate Super Admin login and dashboard
- Admin creation form (preview only)
- Blue and white responsive design

## Important
This is frontend-only. Login, balances, ad rewards, admin creation, withdrawals, and settings are demonstrations and are not connected to a backend or real payments. Do not enter real passwords or bank details. The next development phase is Node.js/Express API + MySQL authentication, roles, ledger, ad-provider callbacks, and verified payment integration.
